Sentinel Core Architecture

Engineered For Zero Operational Overhead

Traditional security checks rely on humans remembering to run tools. Posture Watch runs in your CI pipeline, detects state drift, and reports to your issue tracker.

Automated Cadence

Configure a cron schedule in your repository. Posture Watch executes on GitHub-hosted runners on your chosen interval without external SaaS webhooks or hosted databases.

Secret-Sanitized Errors

Custom token scrubber automatically intercepts all error streams and strips GitHub PATs, OAuth tokens, and 40-character hex keys before any message can reach GitHub Action logs.

Hermetic Compilation

Requires an exact 40-character commit SHA for the Gauge binary. Eliminates supply chain poisoning by preventing upstream tag moves or branch drift from altering the verification engine.

Stateful Idempotent Synchronization

Maintains exactly one tracking issue per policy. Matches existing issues via embedded HTML state markers rather than fragile title strings, ignores pull requests automatically, and leaves the issue unedited when findings haven't moved.

Fail-Fast Auth Guards

Aborts instantly on HTTP 401 or non-rate-limited 403 errors rather than burning through retries, protecting your GitHub organization tokens against abuse rate-limit lockouts.

Execution Lifecycle

The Four-Stage Sentinel Pipeline

Every run executes a predictable, hermetic sequence designed to guarantee zero false positives and trace all claims to verifiable ledger bytes.

01 // TRIGGER

Cadence Event

Fires on scheduled cron or workflow_dispatch. Validates all inputs before making any network or API calls.

02 // COMPILE

Build Gauge

Fetches the exact pinned Gauge commit SHA, compiles the Go binary hermetically, and caches for instant re-runs.

03 // AUDIT

Horizon Read

Reads account signers, weights, master key status, and thresholds. Compares against local gauge.toml policy.

04 // SYNC

Issue Update

Locates existing issue via state marker. If findings drifted, updates markdown body with zero token leaks. If clean, leaves intact.

        Verification & Trust
        
Cryptographic Security Invariants

        
Guarantees enforced by automated unit and integration suites on every change.

      


      

        

          
🔒 Token Redaction Guarantee

          
Every error path passes through regex scrubbing. Fine-grained PATs (github_pat_), classic PATs (ghp_), and 40-character hex sequences are replaced with [redacted].

        

        

          
⚡ Downstream Execution Guard

          
Issue modification steps are strictly guarded with if: exit-code == '0' || exit-code == '1'. An engine crash (exit 2/3) uploads diagnostics and immediately halts without touching issues.

        

        

          
🛡️ PR Isolation

          
The issue resolution search excludes items containing pull_request metadata, ensuring pull requests are never mistakenly closed or modified by scheduled sentinel runs.
